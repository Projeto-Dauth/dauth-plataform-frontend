# Produtos e Pedidos

![Formulário de novo pedido de produto](/docs-images/admin-produtos.webp)

## 1. Cadastrar um produto

Preencha:

| Campo | Obrigatório? | O que é |
|---|---|---|
| **Nome** | Sim | Nome do produto (shampoo, cosmético, etc.) |
| **Preço** | Sim | Valor de venda |
| **Estoque** | Sim | Quantidade disponível |

## 2. Registrar um pedido para um cliente

1. Escolha o cliente e o produto.
2. Defina a quantidade.
3. O pedido fica como **encomendado** até ser pago.

O pagamento pode ser feito depois, na aba Produtos do Caixa, ou junto com o fechamento de uma comanda de serviço do mesmo cliente.

## Controle de estoque

O estoque é verificado automaticamente ao registrar um pedido: se não houver quantidade suficiente, o sistema avisa e não deixa continuar.
