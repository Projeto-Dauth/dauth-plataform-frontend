# Meu perfil

![Tela de perfil com o botão de exportar dados em destaque](/docs-images/admin-perfil.webp)

## 1. Editar seus dados

| Campo | O que é |
|---|---|
| **Nome** | Seu nome |
| **Telefone** | Usado para login |
| **Data de nascimento** | — |

## 2. Trocar sua senha

Informe a senha atual e a nova senha para atualizar o acesso.

## 3. Exportar meus dados

O botão **Exportar meus dados** baixa um arquivo com todas as suas informações e histórico de agendamentos — útil para conferência ou solicitação de dados pessoais (LGPD).
