# Serviços e Categorias

Aqui você cadastra tudo o que o salão oferece — corte, coloração, escova, etc. — e organiza em categorias.

![Formulário de cadastro de serviço, com o botão de criar categoria inline](/docs-images/admin-servicos.webp)

## 1. Criar uma categoria

| Campo | Obrigatório? | O que é |
|---|---|---|
| **Nome** | Sim | Nome da categoria |

Você pode criar uma categoria nova direto na hora de cadastrar um serviço, sem precisar sair da tela (botão **+** ao lado do campo).

## 2. Cadastrar um serviço

| Campo | Obrigatório? | O que é |
|---|---|---|
| **Nome** | Sim | Nome do serviço |
| **Categoria** | Sim | Categoria criada anteriormente |
| **Duração** | Sim | Usada para calcular automaticamente o horário de término ao agendar |
| **Preço** | Não | Pode ficar em branco/zero — aparece como "Consultar" para o cliente |
| **Comissão** | Sim | Percentual que o profissional recebe sobre esse serviço |

## 3. Vincular profissionais a um serviço

![Formulário de vínculo de profissionais ao serviço](/docs-images/gerenciar-servicos.webp)

Dentro do serviço, adicione ou remova profissionais que podem atendê-lo. Isso afeta:

- Quais profissionais aparecem na Agenda para aquele serviço.
- Quais profissionais o cliente pode escolher no agendamento público.
