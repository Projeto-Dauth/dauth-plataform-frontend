# Convidar profissional

Para adicionar um novo profissional à equipe, você não cadastra a senha dele diretamente — o sistema envia um convite.

![Formulário de convite de profissional](/docs-images/admin-convidar-profissional.webp)

## 1. Enviar o convite

Preencha:

| Campo | Obrigatório? | O que é |
|---|---|---|
| **Nome** | Sim | Nome do profissional |
| **E-mail** | Sim | Para onde o convite é enviado |

## 2. O profissional aceita o convite

1. Ele recebe um e-mail com um link.
2. Ao clicar no link, define telefone, data de nascimento e senha por conta própria.
3. Assim que confirma, o acesso já libera direto no painel de profissional.

## 3. Depois do convite aceito

- Vá em **Serviços** para vincular o novo profissional aos serviços que ele vai realizar.
- Peça para ele (ou cadastre por ele) em **Meus horários**, para definir a agenda semanal de trabalho.
