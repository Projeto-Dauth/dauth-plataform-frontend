# Pacotes

A página **Pacotes** aparece no menu quando o Admin libera a venda de pacotes para os profissionais. Se você não a vê, peça ao Admin.

Aqui você vê os pacotes ativos do salão (nome, validade, preço e serviços) e a aba **Pacotes vendidos**, com o andamento de cada cliente.

## Vender um pacote

Clique em **Vender** no card, escolha o cliente e confirme. É criada uma comanda em aberto: o pagamento é registrado no Caixa, como qualquer outro serviço. Um cliente só pode ter um pacote ativo ou pendente por vez.

Criar, editar, desativar e excluir pacotes continua sendo só do Admin.
